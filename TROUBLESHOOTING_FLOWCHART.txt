## 🆘 QUICK FIX COMMANDS

### **Port Already in Use:**
```
taskkill /F /IM node.exe
```
Wait 5 seconds, run START_APP.bat again

### **Website Blank/404:**
```
Close terminals with Ctrl+C
Delete: frontend/.next folder (if it exists)
Run START_APP.bat again
```

### **Slow Performance:**
```
Close Chrome, heavy apps
Restart computer
Run START_APP.bat
```

### **Database Not Connecting:**
```
Check internet connection
Restart computer
Check MongoDB credentials in backend/.env
```
