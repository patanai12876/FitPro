# ⚡ QUICK START - ONE PAGE

## 🟢 START

```
Double-click: START_APP.bat
Wait 10 seconds
Go to: http://localhost:3000
```

---

## ✅ WORKING?

Check these 3 windows:

| Window | Should Show |
|--------|------------|
| **Backend** (Dark) | ✅ MongoDB Connected |
| **Frontend** (Dark) | ✓ Ready |
| **Browser** | Website visible + content loads |

---

## ❌ NOT WORKING? FIXES

| Error | Fix |
|-------|-----|
| "Port already in use" | Close terminals, run `START_APP.bat` again |
| Website shows 404 | Close terminals, run `START_APP.bat` again |
| Blank page / no data | Wait 20 seconds, refresh browser (F5) |
| Can't see plans/services | Backend not connected to database |
| Form won't submit | Same as above |
| Website very slow | Close Chrome, heavy apps, try again |

---

## 🔥 NUCLEAR OPTION (Fixes Everything)

```bash
taskkill /F /IM node.exe
```
Then: Run `START_APP.bat` again
