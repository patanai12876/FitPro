## 📸 HOW TO ADD IMAGES

### **FOR SERVICES** (`/images/services/`)

Add images with these EXACT names:

```
personal-training.jpg      (Strength training)
cardio-classes.jpg         (Cardio)
yoga.jpg                   (Flexibility)
group-fitness.jpg          (Group classes)
recovery.jpg               (Recovery)
nutrition.jpg              (Nutrition)
strength.jpg               (Strength)
boxing.jpg                 (Cardio)
pilates.jpg                (Flexibility)
spin.jpg                   (Cardio)
crossfit.jpg               (Strength)
stretching.jpg             (Flexibility)
```

### **FOR TRAINERS** (`/images/trainers/`)

Use naming format: `trainer-[firstName-lastName].jpg`

Example:
```
trainer-john-doe.jpg
trainer-jane-smith.jpg
trainer-mike-johnson.jpg
```
